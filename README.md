## Planning decisions
Goal: explain the research to assessors, researchers and collaborators, making independent component evidence and supporting documents easy to find.
Structure: one indexed page; assets/css, assets/images and documents folders.
Design: restrained botanical palette, serif display accents, consistent cards and ample reading space; responsive mobile and desktop layouts.
Navigation: seven guideline sections, a component index and milestone dropdown, with a skip link and keyboard-visible focus states.
Assets: supplied source documents and original optimized SVG; no external fonts, libraries or remote images.
